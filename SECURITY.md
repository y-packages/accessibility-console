# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :---: |
| 4.x | Yes |
| 3.x | Security fixes only |
| < 3.0 | No |

## Reporting a Vulnerability

**YakNet** takes the security of open-source packages seriously. If you discover a security vulnerability in **YakNet Accessibility Console** (for example, in HTML/XML parsing, URL crawling, Headless Chrome rendering, webhook signing, or report generation):

1. **Do not** disclose the issue publicly in an open GitHub issue before it has been reviewed.
2. Report it privately by emailing `info@yakhub.com.tr` or opening a private security advisory on the repository.
3. Include a clear description, reproduction steps, affected version, and potential impact.

We aim to acknowledge reports within 48 hours and provide a coordinated fix and release advisory promptly.
